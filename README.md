## Installatie

```bash
git clone https://github.com/itsdarklikehell/RetroPie-Nointro-Full-Romsets.git
cd RetroPie-Nointro-Full-Romsets
chmod +x Romset-Downloader.sh
```

## Gebruik

```bash
# Download alle romsets
./Romset-Downloader.sh

# Download specifiek systeem
./Romset-Downloader.sh --system "Nintendo (All Regions)"

# Lijst van ondersteunde systemen
./Romset-Downloader.sh --list
```
